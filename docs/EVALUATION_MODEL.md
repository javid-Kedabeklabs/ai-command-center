# Evaluation Model

Evaluation suites contain deterministic checks and bounded history. Checks currently support contains, not-contains, minimum length, JSON validity, and regular expressions. Results include score, pass/fail, individual evidence, timestamp, and optional run ID; attached results are persisted into the run record.

Workflows may declare required evaluation IDs as production promotion gates. Missing or failing latest evidence blocks promotion. Model-graded, visual, accessibility, security, and performance evaluators remain later adapters and may never be the sole judge for consequential promotion.

Learning proposals are evidence-derived, diffed changes requiring explicit approval; locked production workflows are not silently changed.
