# Testing Evidence

The release checkpoint includes reducer/control/trigger/subworkflow recovery, secret canaries, disk-full and concurrency soak, measured DAG/checkpoint/atomic-write ceilings, backup/restore, clean package/install/upgrade/rollback, SBOM and dependency audit, evaluation/learning, Agent Architecture migration/rollback, TypeScript/build, and eleven live browser/Axe/visual journeys.

Run `npm run verify:release` for the authoritative gate, `npm run test:hardening` for disk/soak/performance checks, or see root `TESTING.md` for focused commands. Host-duration soak may add operational confidence, but the deterministic release contract no longer depends on unbounded waiting.

Additive amendment suites include `node scripts/collaboration-foundation-tests.mjs` for task packets, path/ownership conflicts, structured event/result parsing, redaction, capacity, backoff, and model fallback; `node scripts/collaboration-state-tests.mjs` for atomic task state and file ownership, restart recovery, corruption, owned processes, repository/executable/environment bounds, and cancellation; `node scripts/collaboration-worktree-tests.mjs` for durable leases, sparse sensitive-tree exclusion, bounded runtime-data dirt, restart reconciliation, unknown-worktree preservation, commit/scope/symlink verification, explicit integration, conflict abort, and guarded cleanup; `node scripts/collaboration-api-tests.mjs` for sanitized status, explicit mutation intent, packet validation/idempotency, default dispatch denial, and path-safe lease evidence; `node scripts/collaboration-dispatcher-tests.mjs` for host opt-in, exact Claude capability verification, task→lease→PID→model→commit receipts, blocked capacity, and reviewed-base denial; `node scripts/agent-role-card-tests.mjs` for primitives and isolated resolution; `node scripts/agent-architecture-store-tests.mjs` for revisioned persistence, assignments, migration, rollback, replay, and corruption; `node scripts/agent-architecture-live-tests.mjs` for the live API and legacy preservation; and `node scripts/trigger-folder-tests.mjs` for the pure hardened folder foundation. Normal tests use fixtures and never consume live Codex or Claude capacity. A live Claude task is a separate explicit operational gate.
